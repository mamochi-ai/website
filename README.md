# うつろい暦

七十二候を、一枚の屏風で。

開いた日の「候」（約5日ごとの季節）を、端末の中だけで天文計算して描くウェブサイトです。
サーバーも外部APIも使いません。`index.html` ひとつで完結し、スマートフォンだけで動きます。

## 遊びかた

| 操作 | 何が起きるか |
| --- | --- |
| 画面を左右になぞる / 下のダイヤルを回す | 一年がめぐり、空・山・水・枝・舞うものが連続して移り変わる |
| `‹` `›` / キーボードの ← → | ひとつ前・次の候へ |
| 右上の題（縦書き）に触れる / 上へスワイプ | 巻物がひらく。意味・解説・この候の色・月の満ち欠け・暦の行事・小さな楽しみ |
| 太陽や月を左右に動かす | 時刻が変わる（夕焼け、夜、月の出） |
| 太陽・月に触れる | 日の出・日の入り / 月の名前と月齢 |
| 水面に触れる | 波紋がひろがる。枝の小鳥に触れると飛び立つ |
| 音 | 鳥・虫・風・雨などの環境音を、その場で合成して鳴らす（録音素材なし） |
| 絵 | 今の情景を絵葉書（1200×1800 の PNG）にする |
| 巻物の「来年の、この候へ」 | 書いた言葉は端末に保存され、一年後の同じ候にひらく |
| 今へ戻る | 今日・今の時刻へ |

## しくみ

- **天文計算**: 太陽黄経（Meeus の略算式）から二十四節気・七十二候の日時を毎年計算。月の黄経から月齢・満ち欠け、太陽と月の高度から空の色を決める（東京基準）。
- **描画**: Canvas 2D。金箔の霞（すやり霞）、富士、山肌の点描、水面の映り込み、季節で姿を変える一本の枝、天候ごとの粒子。夜は金箔が銀箔に変わる。
- **音**: Web Audio API による完全な合成。鶯・ひぐらし・鈴虫・風鈴・梵鐘・鹿威しなど。
- **データ**: 72候それぞれの読み・意味・解説・伝統色・天候・草花・音を `src/data.js` に収録。
- **通信**: 一切しない（フォントも端末のものを使う）。

## ファイル

```
index.html          ビルド済みの完成品（これだけで動く）
src/                元のソース
  astro.js          天文計算（節気・候・月・太陽高度・行事）
  data.js           七十二候のデータと文
  motifs.js         花びら・葉・鳥・草花などの絵
  sound.js          環境音の合成エンジン
  scene.js          情景の描画
  main.js           操作・ダイヤル・巻物・絵葉書・開幕
  style.css         見た目
  index.template.html
tools/build.mjs     src を index.html に一本化する
```

ビルド: `node tools/build.mjs`（依存パッケージなし）

## スマートフォンで開くには

- `index.html` を端末に保存してブラウザで開く、または
- GitHub Pages などの静的ホスティングに置く（サーバー側の処理は不要）。
  iPhone なら Safari の共有メニューから「ホーム画面に追加」で、全画面のアプリのように使えます。
